# 高山無線電站台 VR 地圖 · Mountain Radio-Station VR Map

一個結合 **地圖** 與 **AR / VR 視角** 的無線電高山站台（中繼台）路徑規劃工具。
靈感來自「抬頭辨識山峰」的 AR App：把要通聯的高山站台疊在地平線上，
同時算出 **直線距離、方位角、目標仰角**，並判斷 **中間有沒有山擋住**（視線／
無線電路徑地形遮蔽分析）。

![概念](docs/concept.png)

## 功能 Features

| 需求 | 對應功能 |
| --- | --- |
| 標記我的位置與對面站台位置 | 地圖上可拖曳「📍我的位置」、點空白處新增站台、GPS 定位 |
| 直線距離在哪裡？ | Haversine 大圓距離（照片中的「距離 95 公里」） |
| 位置在哪裡？方向？ | 方位角 + 8/16 方位中文標示、目標仰角 |
| 高山無線電站台 | 站台/中繼台資料，含天線高度、頻率 |
| 中間有沒有山擋住？ | 沿路徑取樣地形剖面，含 **地球曲率** 與 **菲涅耳區** 判斷遮蔽 |
| VR 概念 | AR 全景視角：站台依方位/仰角疊在地平線，附瞄準線與即時讀數 |

| 涵蓋範圍 | 依無線電視距在地圖畫各站台涵蓋圈 |
| 自訂資料 | 新增/編輯/刪除站台、GPS 定位、localStorage 保存、JSON 匯入匯出 |

## 三個核心視角

1. **AR 視角** — 重現照片：地平線 + 羅盤 + 站台標籤（名稱／海拔／距離），
   選定目標後畫出藍色瞄準線並顯示 `海拔 / 距離 / 方位 / 仰角 / 視線狀態`。
   - 手機（HTTPS）：可開啟 🧭 羅盤（DeviceOrientation）與 📷 相機背景，做到真正的 AR。
   - 桌機：拖曳畫面即可左右轉向、上下俯仰。
2. **地圖** — Leaflet + OpenStreetMap，顯示所有點位；畫出「我 → 目標」路徑，
   **被地形擋住的路段染成紅色**。
3. **路徑分析面板** — 地形剖面圖（地形、第一菲涅耳區、視線），
   文字結論（通 / 繞射 / 擋），以及理論無線電視距上限。

## 判斷邏輯（「有沒有山擋」）

沿兩點大圓路徑取樣 N 點，向 Open-Meteo Elevation API 取地面海拔，然後：

```
視線高度  L(d)       = h1 + (h2 - h1) · d/D              // 兩端天線頂連線
地球隆起  bulge(d)   = d·(D−d) / (2·k·R)                 // k=4/3 等效地球半徑
淨空      clearance  = L(d) − ( ground(d) + bulge(d) )
菲涅耳    F1(d)       = √( λ·d·(D−d)/D )
```

- `clearance < 0` → **視線被地形擋住（擋）**
- `clearance ≥ 0` 但 `clearance / F1 < 0.6` → 視線可通、但菲涅耳區未淨空（**繞**射損耗）
- 皆滿足 → **路徑良好（通）**

### 連結預算 Link budget

```
路徑損耗 = 自由空間損耗 FSPL + 刀刃繞射損耗（ITU-R P.526 近似）
FSPL(dB) = 20log10(d_km) + 20log10(f_MHz) + 32.44
接收功率 = EIRP + 接收天線增益 − 路徑損耗
連結餘裕 = 接收功率 − 接收機靈敏度        // ≥10 dB 佳、≥0 dB 勉強、<0 不通
```

繞射損耗以路徑上繞射參數 `v = -√2·(clearance/F1)` 最大處估算。
EIRP、接收增益、靈敏度可在「進階：連結預算」中調整。

## 使用 Usage

純靜態網頁，無需建置。用任一靜態伺服器開啟（相機/感測器需 HTTPS）：

```bash
python3 -m http.server 8000
# 瀏覽 http://localhost:8000
```

> 地圖圖磚與高程分析需要對外網路（`tile.openstreetmap.org`、`api.open-meteo.com`）。
> 離線時仍可顯示距離、方位與 AR 視角，僅無法做地形遮蔽判斷。

## 檔案結構

```
index.html            介面骨架與分頁
css/style.css         樣式
js/geo.js             地理/RF 數學（距離、方位、仰角、曲率、視距、菲涅耳）
js/elevation.js       高程 API + 地形剖面 + 遮蔽分析
js/data.js            範例站台/山峰資料（座標為概略值，請自行校正）
js/map.js             Leaflet 地圖視角
js/ar.js              AR/VR 全景視角
js/app.js             主控制器
vendor/leaflet/       內建 Leaflet（免 CDN）
```

## 注意

- `js/data.js` 內的座標與高程為 **概略示範值**，用來對應照片中的山峰；
  正式規劃請以精確測量座標取代，或直接在地圖上點選校正。
- 遮蔽分析採「單一直線 + 曲率 + 菲涅耳」模型，未計入植被、建物、繞射增益等；
  屬規劃參考，非精確 RF 模擬。
